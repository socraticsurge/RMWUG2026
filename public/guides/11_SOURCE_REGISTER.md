# Source Register

**Last checked:** 10 August 2026

## How to read this register

These sources informed the teaching and editorial standards in this kit. The kit sometimes adapts guidance created for other fields or institutions. The adaptation is identified; the source is not claimed to have endorsed this workshop.

Policies, standards, tools and repository features can change. Recheck current institutional policy and the canonical links before workshop delivery or public release.

## Local standards created by this kit

The following are workshop-specific editorial decisions, not requirements copied from a single source:

- 80 topics organized into eight sections;
- 700–900 word research-note form;
- Claim → Corpus → Capture → Code → Check → Compose method;
- 12–25 artifact target;
- one row per organization/source × eligible artifact by default;
- 100% author verification and at least 20% independent checking of ordinary rows;
- `ai_proposed_*` fields retained separately from human-accepted fields;
- ordinary 25-consecutive-word limit for published excerpts from one artifact;
- v0.9 private compilation followed by v1.0 public-release gate; and
- internal 100-point editorial rubric.

These rules should be evaluated after the first workshop. Record deviations and lessons rather than quietly changing the historical version.
